## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) to run the JavaScript solutions locally.

### Clone the repository

```bash
git clone https://github.com/Madhan-011/JavaScript-DSA.git
```

### Navigate to the project

```bash
cd JavaScript-DSA
```

### Run a solution

Navigate to the relevant topic folder and execute a JavaScript file using Node.js.

```bash
node 3_Recursion/3.7_Fibonacci_Number.js
```

Replace the file path with the solution you want to run.

## 📈 Learning Approach

For each problem, I aim to:

1. Understand the problem and its constraints.
2. Develop a logical approach before coding.
3. Implement the solution in JavaScript.
4. Test it with different inputs and edge cases.
5. Analyze time and space complexity where applicable.
6. Improve the solution when a more efficient approach exists.
